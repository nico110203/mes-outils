Compresseur d'images

Compression qualité maximale, suppression des données EXIF, renommage automatique. Tout se passe dans votre navigateur — aucune image n'est envoyée où que ce soit.

Cliquez pour choisir des images ou glissez-déposez-les ici

JPEG, PNG, WebP — plusieurs fichiers acceptés

Le format PNG est compressé sans perte réelle (pixels identiques). Pour JPEG/WebP, une qualité ≥ 0.92 est visuellement indiscernable de l'original tout en réduisant nettement la taille du fichier ; c'est le meilleur compromis disponible dans un navigateur, un JPEG "sans aucune perte" n'existant pas techniquement pour ce format. Le recodage via canvas retire automatiquement toutes les métadonnées EXIF (GPS, appareil photo, date, etc.). Le téléchargement se fait fichier par fichier — si votre navigateur bloque les téléchargements multiples, autorisez les pop-ups/téléchargements pour cette page.
